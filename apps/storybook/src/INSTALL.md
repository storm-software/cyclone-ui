# Installing Storybook Token Docs

Generated by `@razorwind/storybook`.

## Files

- `apps/storybook/src/Tokens.mdx` — token overview (Cyclone UI)
- `apps/storybook/src/blocks/` — React doc blocks (ColorPalette, Typeset, …)
- `apps/storybook/src/tokens.json` — flattened token manifest

## Storybook UI theme

Generated theme module:

- `theme.ts` — record of `create()` themes keyed by name (`dark`, `light`)

Wire into `.storybook/preview.ts`:

```ts
import themes from "../theme.ts";

export const parameters = {
  docs: { theme: themes["dark"] }
};
```

## Token-doc variants

Generated token blocks follow Storybook's `theme` global when it matches one
of these token-set names: `dark`, `darkDimmed`, `darkHighContrast`, `light`, `lightDimmed`, `lightHighContrast`.
Pass `theme` directly to a block to override that selection.

## Setup

1. Add the generated MDX pages to Storybook (paths depend on your `stories` config):

```ts
// .storybook/main.ts
export default {
  stories: [
    "../apps/storybook/src/**/*.mdx"
  ]
};
```

2. Import doc blocks in MDX as needed:

```mdx
import { ColorPaletteBlock } from "./blocks";
```

3. Start Storybook and open **Cyclone UI** in the sidebar.

## Regenerate

Re-run Razorwind generate when tokens change to refresh docs under `apps/storybook/src/`.
