# Contributing

The repository guide is [`.github/CONTRIBUTING.md`](https://github.com/storm-software/cyclone-ui/blob/main/.github/CONTRIBUTING.md).

## Report or claim work

1. Read the [issues](https://github.com/storm-software/cyclone-ui/issues).
2. Open an issue, or comment on an existing issue, before a large change.
3. After you have a go-ahead, open a pull request and link the issue.

A small change can go straight to a pull request.

## Code

- Fix the warnings from Biome, ESLint, Markdownlint, Prettier, and `.editorconfig` in the code you submit.
- Add unit tests for the code you write.

Support contacts from the CLI package manifest:

- Issues and support: <https://stormsoftware.com/support>
- Email: support@stormsoftware.com
