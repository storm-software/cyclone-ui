## Setup

1. Ensure `components.json` points at this registry URL or local path.

2. Add items from the registry:

```bash
npx shadcn@latest add button --registry ./registry.json
```

Or publish `registry.json` and reference it in `components.json`:

```json
{
  "registries": {
    "@cyclone-ui": "./registry.json"
  }
}
```
