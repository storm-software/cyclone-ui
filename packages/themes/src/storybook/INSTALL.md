# Installing Storybook Token Docs

Generated by `@razorwind/storybook`.

## Files

- `packages/themes/src/storybook/Tokens.mdx` — token overview (Cyclone UI)
- `packages/themes/src/storybook/blocks/` — React doc blocks (ColorPalette, Typeset, …)
- `packages/themes/src/storybook/tokens.json` — flattened token manifest

## Storybook UI theme

Generated theme module:

- `theme.ts` — record of `create()` themes keyed by name (`dark`, `light`)

Wire into `.storybook/preview.ts`:

```ts
import themes from "../theme.ts";

export const parameters = {
  docs: { theme: themes["dark"] }
};
```

## Setup

1. Add the generated MDX pages to Storybook (paths depend on your `stories` config):

```ts
// .storybook/main.ts
export default {
  stories: [
    "../packages/themes/src/storybook/**/*.mdx"
  ]
};
```

1. Import doc blocks in MDX as needed:

```mdx
import { ColorPaletteBlock } from "./blocks";
```

1. Start Storybook and open **Cyclone UI** in the sidebar.

## Regenerate

Re-run Razorwind generate when tokens change to refresh docs under `packages/themes/src/storybook/`.
