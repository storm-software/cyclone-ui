# Installing Cyclone UI (Light High Contrast)

Generated by `@razorwind/shiki`.

## Files

- `cyclone-light-high-contrast.json` — Cyclone Light (theme id: `cyclone-lightHighContrast`)

## Setup

1. Copy or import the generated JSON into your app (paths depend on your bundler).

2. Register themes when creating a Shiki highlighter:

```ts
import { createHighlighter } from "shiki";
import theme from "./cyclone-light-high-contrast.json";

const highlighter = await createHighlighter({
  themes: [theme],
  langs: ["javascript"]
});

const html = highlighter.codeToHtml("const x = 1", {
  lang: "javascript",
  theme: "cyclone-lightHighContrast"
});
```

Or load at runtime:

```ts
import { readFile } from "node:fs/promises";

const theme = JSON.parse(
  await readFile("./cyclone-light-high-contrast.json", "utf8")
);
await highlighter.loadTheme(theme);
```

## Select / load theme

Pass the theme id to `codeToHtml`, `codeToTokens`, or `getTokenStyle`:

- `cyclone-lightHighContrast` — Cyclone Light
