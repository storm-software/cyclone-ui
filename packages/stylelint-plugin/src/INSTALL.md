# Installing the Stylelint Design-System Plugin

Generated by `@razorwind/stylelint` from 643 tokens, 92 components, 0 fonts.

## Files

- `packages/stylelint-plugin/src/index.ts` — Stylelint plugins whose rules are derived from the design system

## Setup

1. Install the runtime the generated module imports:

```bash
pnpm add -D @razorwind/stylelint stylelint
```

2. Add the plugins and rules to `stylelint.config.mjs`:

```js
import designSystem from "./packages/stylelint-plugin/src/index.ts";

const { plugins, rules } = designSystem({
  // Domains ensure-design-token-usage checks (colors and shadows by default).
  tokenUsage: { color: true, spacing: true },
  // "forced" requires var(--token, fallback), "none" forbids fallbacks.
  fallbackUsage: "optional",
  severity: { "no-physical-properties": "error" }
});

export default {
  plugins: [...plugins],
  rules: { ...rules }
};
```

Passing `files` moves the rules into an `overrides` entry for those globs.

3. Deliberate one-offs carry an inline, reviewable exception:

```css
/* stylelint-disable-next-line cyclone-ui/ensure-design-token-usage -- <reason> */
```

## Rules

Token rules are enabled when the design system defines that token category.
Literals that match exactly one token's value are fixed by `stylelint --fix`.

| Rule | Default | Description |
| ---- | ------- | ----------- |
| `cyclone-ui/ensure-design-token-usage` | error | Enforces usage of design tokens rather than hard-coded colors and shadows (and, when enabled, spacing, typography and non-token custom properties) |
| `cyclone-ui/use-tokens-space` | warn | Enforces usage of space design tokens rather than hard-coded values |
| `cyclone-ui/use-tokens-shape` | warn | Enforces usage of shape (radius and border width) design tokens rather than hard-coded values |
| `cyclone-ui/use-tokens-typography` | warn | Enforces usage of typography design tokens rather than hard-coded font values |
| `cyclone-ui/use-tokens-motion` | warn | Enforces usage of motion design tokens rather than hard-coded durations and easings |
| `cyclone-ui/no-unsafe-design-token-usage` | error | Enforces that token references exist in the design system and follow the fallback strategy |
| `cyclone-ui/no-deprecated-design-token-usage` | off | Disallow using deprecated design tokens |
| `cyclone-ui/no-margin` | off | Disallow using the margin CSS property |
| `cyclone-ui/no-physical-properties` | off | Disallow physical properties and values; use logical properties that follow the reading direction |
| `cyclone-ui/expand-motion-shorthand` | off | Expands transition and animation shorthands so each value can use a motion token |
| `cyclone-ui/use-visually-hidden` | warn | Enforce usage of the design system's visually hidden component over hand-rolled styles |
