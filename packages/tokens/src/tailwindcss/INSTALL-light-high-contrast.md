# Installing Tailwind Theme CSS

Generated by `@razorwind/tailwindcss`.

## Files

- `packages/tokens/src/tailwindcss/tokens.css` — Tailwind v4 theme entry (The file contains `@theme` token mappings (no `@import "tailwindcss"`).)

## Setup

1. Import the generated CSS in your app entry (or merge into your existing Tailwind entry):

```ts
import "./packages/tokens/src/tailwindcss/tokens.css"
```

2. Ensure your build uses Tailwind v4 (Vite plugin, PostCSS, or CLI).

3. Use generated theme tokens as utilities or arbitrary values, e.g. `bg-primary` when `--color-primary` is defined in `@theme`.

## Regenerate

Re-run Razorwind generate when design tokens change so `packages/tokens/src/tailwindcss/tokens.css` stays in sync.
