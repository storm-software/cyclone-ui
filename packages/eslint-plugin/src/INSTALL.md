# Installing the ESLint Design-System Plugin

Generated by `@razorwind/eslint` from 643 tokens, 92 components, 0 icons, 0 fonts.

## Files

- `packages/eslint-plugin/src/index.ts` — ESLint flat-config plugin whose rules are derived from the design system

## Setup

1. Install the runtime the generated module imports:

```bash
pnpm add -D @razorwind/eslint
```

2. Add the plugin to `eslint.config.mjs`:

```js
import designSystem from "./packages/eslint-plugin/src/index.ts";

export default [
  // ...
  designSystem({
    files: ["src/**/*.{ts,tsx}"],
    // How suggested fixes reference tokens: "css-var" or "function".
    tokenReference: "css-var",
    // Only treat components imported from these modules as design-system components.
    // componentModules: ["@acme/ui"],
    severity: { "no-physical-properties": "error" }
  })
];
```

3. Deliberate one-offs carry an inline, reviewable exception:

```ts
// eslint-disable-next-line cyclone-ui/ensure-design-token-usage -- <reason>
```
